# 游戏教程

本栏目是可逐步扩展的教程入口。每个模组或主题使用独立 Markdown 文件维护，便于版本更新和多人协作。

## 教程分类

### 科技

计划收录 AE2、机械动力、Mekanism、工业升级与自动化系统等内容。

### 魔法与农业

计划收录植物魔法、神秘农业及其与科技系统的联动内容。

### 探索与终局

计划收录世界介绍、资源探索、阶段目标与终局挑战。

## 新增教程模板

在本目录新建例如 `ae2.md` 的文件后，按以下方式写作即可：

```md
# AE2 教程

## ME 网络

内容……

## 自动合成

内容……
```

随后在 `.vitepress/config.mts` 的 `sidebar` 中添加链接。详细说明请查看项目根目录 README。

::: info
教程内容均以服务器实际启用的模组、配置与版本为准。占位分类不代表所有模组均已开放。
:::
