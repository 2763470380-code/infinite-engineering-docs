# 萌新指南

欢迎来到无限工程。这里的内容会帮助你从第一次进入服务器开始，逐步熟悉服务器环境与基础玩法。

## 开始游戏

请先确认 Minecraft 客户端、NeoForge 版本和服务器整合包与公告要求一致。具体下载方式与连接地址将在服务器公开后在本页补充。

::: tip 建议
第一次进入前，建议先完整阅读 [服务器规则](/rules/)；它比任何单一教程都更重要。
:::

## 进入服务器

1. 使用公告指定的客户端与模组配置启动游戏。
2. 在多人游戏界面添加服务器地址（待公布）。
3. 初次进入后，按聊天栏或新手任务的引导完成基础设置。

## 前期目标

前期不必急于追赶进度。建议先建立安全据点、整理资源并熟悉任务线，再选择科技或魔法方向深入发展。

## 基础指令

服务器可用指令、权限范围及使用示例将在功能确认后补充。请勿依赖来源不明的指令说明。

::: warning
如遇卡顿、物品丢失或异常，请保留发生时间、所在维度与必要截图，便于管理人员排查。
:::
