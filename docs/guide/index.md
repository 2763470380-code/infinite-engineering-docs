# 萌新指南

本指南面向第一次接触无限工程的玩家。请按顺序完成客户端启动、进入服务器、QQ 绑定和登录流程；遇到不确定的提示时，以游戏内实际说明为准。

## 开始游戏

请先确认 Minecraft 客户端与服务器当前版本要求一致。客户端始终以无限工程 QQ 群群文件中的最新版本为准。

下载客户端后，请将客户端文件**完整解压**到桌面或其他便于找到的文件夹，再运行客户端内的 PCL 启动器并启动「无限工程」客户端。

::: warning 请勿直接在压缩包内启动
不要直接在压缩包中运行启动器。必须先将客户端完整解压，否则可能导致文件缺失、配置无法保存或启动异常。
:::

## 进入服务器

使用最新客户端启动游戏后，进入多人游戏的服务器列表。你可以选择「主线路」或「备用线路」进入服务器。

两条线路仅提供不同的连接入口，实际游戏内容没有区别；可根据自己的网络情况选择连接更稳定的一条。

::: tip
若连接或加载出现异常，先确认客户端是否来自 QQ 群群文件中的最新版本，再尝试另一条线路。
:::

## 首次绑定 QQ

首次进入服务器时，你会收到一个数字验证码。请按以下步骤完成游戏账号与 QQ 账号绑定：

1. 记录游戏中显示的数字验证码。
2. 前往无限工程 QQ 群。
3. 在群内发送该数字验证码。
4. 等待游戏账号与 QQ 账号完成绑定。
5. 绑定完成后，重新进入服务器。

::: info
验证码用于确认绑定身份。请以游戏内显示的验证码为准，不要向无关人员提供账号或密码。
:::

## 注册与登录

QQ 绑定完成并再次进入服务器后，会进入登录流程。正常情况下会显示铁砧登录页面；首次进入需要设置自己的服务器密码。

例如，可以设置密码：`xxx123321`。

如果没有自动显示注册或登录页面，可在聊天栏手动执行：

| 操作 | 指令 | 示例 |
| --- | --- | --- |
| 注册 | `/reg 密码 密码` | `/reg xxx123321 xxx123321` |
| 登录 | `/l 密码` | `/l xxx123321` |

::: warning 保护你的密码
请牢牢记住自己的服务器密码，不要向其他玩家透露。管理人员不会要求你在聊天中发送密码。
:::

## 初次进入服务器

完成登录后，你会进入服务器主城。建议先完成聊天引导、领取基础福利，并熟悉主城和服务器菜单；之后再选择适合自己的长期发展区域。

## 前期目标

前期不必急于追赶其他玩家的进度。建议先选择一个适合自己的长期发展区域，建立安全、稳定的基地。

### 地皮区域

- 自带地皮保护。
- 无需先学习 FTB Chunks 圈地。
- 适合完全不了解服务器保护系统的萌新。
- 可以较快建立自己的安全基地。

地皮区域并不是低级区域，而是更适合新手开始长期发展的选择。

### 生存区域

- 使用 FTB Chunks 进行圈地保护。
- 更接近 Minecraft 原生生存世界的玩法。
- 推荐作为长期发展的主要区域。
- 更适合建设大型科技、魔法和自动化基地。

::: info 资源获取
请合理使用服务器提供的资源区域和相关系统，尽量避免为了寻找普通资源而在长期发展区域高频、超远距离跑图。
:::

### 家园区域

- 使用 FTB Chunks 进行圈地。
- 属于玩家私人发展的独立区域。
- 可选择服务器提供的预设基地模板。
- 适合喜欢独立空间或预设基地的玩家。

确定长期发展基地后，建议先熟悉服务器菜单。长按 `X` 打开服务器菜单，然后按照「FTB 任务 → 主线章节」中的任务引导逐步发展。

::: tip 推荐发展路线
对于第一次游玩无限工程的玩家，主线任务就是推荐的发展路线。
:::

## 基础指令

| 用途 | 指令 | 说明 |
| --- | --- | --- |
| 向玩家发起传送申请 | `/tpa 玩家ID` | 请求传送到对方身边。 |
| 请求玩家传送到自己这里 | `/tpahere 玩家ID` | 向对方发送「传送到我这里」申请。 |
| 随机传送 | `/rtp` | 部分世界暂未开放随机传送，以游戏内提示为准。 |
| 设置家 | `/sethome A` | `A` 是家的名称，例如 `A`、`B`、`C`、`基地`、`仓库`。 |
| 返回已设置的家 | `/home A` | 返回名为 `A` 的家。 |

默认每位玩家最多可设置 **5 个家**。如果家数量不够，可以使用传送石碑保存重要地点坐标，方便后续快速传送。

## 遇到异常时如何反馈

::: warning 请提供完整信息
如遇服务器明显卡顿、物品异常丢失、机器异常、功能异常或其他疑似 Bug，请尽量保留：

1. 问题发生的大致时间。
2. 当时进行的操作。
3. 所在服务器、区域或世界。
4. 必要截图。

随后发送给腐竹，方便根据日志和时间定位问题。请不要只写「东西没了」「服卡了」或「机器坏了」，却没有发生时间和具体情况。
:::
