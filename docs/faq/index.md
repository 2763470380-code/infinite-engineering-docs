# 常见问题

## 我需要使用什么版本？

服务器定位为 Minecraft NeoForge 1.21.1。具体整合包版本、下载方式和启动参数将在正式发布时公布。

## 服务器地址是什么？

服务器地址尚未公布。本页面不会使用未经确认的地址作为占位，请以官方公告为准。

## 遇到问题应该如何反馈？

请先记录问题出现的时间、操作步骤、所在位置和必要截图。服务器的完整反馈渠道将在后续公告中给出；腐竹联系 QQ：2602346931。

## 为什么我的机器被要求整改？

大型自动化、高频运算或实体堆积可能影响全服性能。请参阅 [服务器规则](/rules/) 中的性能与自动化要求，并配合管理团队调整。

## 赞助后何时到账？

到账流程、人工处理时间和异常处理方式将以 [赞助说明](/sponsor/) 的正式内容为准。请保留必要订单凭证。
