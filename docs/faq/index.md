# 常见问题

本页收录启动客户端、进入服务器与日常游玩中最常见的问题。若问题仍无法解决，请按 [萌新指南](/guide/#遇到异常时如何反馈) 中的要求准备信息后再反馈。

## 为什么启动客户端后会显示「未响应」？

无限工程属于大型 Minecraft 模组服务器客户端，包含大量 Mod。正常启动通常需要 **1～5 分钟**；具体时间会因 CPU、硬盘、分配内存和电脑整体性能而不同。

客户端启动阶段 Windows 暂时显示「未响应」属于常见现象。请耐心等待游戏完成加载，不要频繁点击窗口、重复启动客户端或强行结束进程。

## 最低配置要求是多少？

建议可用运行内存为 **12GB 以上**。大型整合包对 CPU、硬盘和内存均有一定要求，实际体验会因设备状况不同而变化。

::: info
目前未公布特定显卡或 CPU 型号要求；请勿依据非官方硬件清单判断是否能运行。
:::

## 服务器地址是什么？

无限工程必须使用服务器指定的完整客户端进入，不能仅通过一个普通 Minecraft 服务器地址，在其他客户端或原版客户端中直接连接。客户端始终以 QQ 群群文件中的最新版本为准。

## 为什么我的机器会被要求整改？

腐竹不会无缘无故要求玩家拆除机器，更不会故意破坏玩家的正常设备。但以下极端设备可能明显影响服务器稳定：

### 超大型机器阵列

例如同一区域摆放十几个涡轮机、十几个热力蒸馏塔，或大量高负载机器同时持续工作。

### 超大型刷怪场

例如大量刷怪笼长时间保持开启、极高效率设备持续生成大量实体，或长时间无人管理仍满负载运行。

正常的科技发展和自动化建设不会仅因「规模大」就被随意要求整改。只有设备已经实际明显影响 TPS、服务器稳定、区块性能或其他玩家的正常游戏时，才可能需要优化或整改。更多详细要求请参阅 [服务器规则](/rules/)。

## 服务器为什么有时候会卡？

大型模组服务器在大量区块加载、大型机器运行、玩家集中活动、世界生成或自动化高峰等情况下，出现短暂卡顿属于正常现象。

若只是偶发短暂卡顿，一般无需担心；如果出现长时间持续卡顿、操作明显延迟、延迟 ms 长期居高不下、TPS 长时间异常或已经影响正常游玩，请按本页的反馈要求联系腐竹排查。
