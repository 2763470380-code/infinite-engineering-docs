# 服务器规则

本规则用于维护长期、稳定且友好的游戏环境。进入服务器即视为理解并同意遵守以下原则；细则会随服务器运营持续更新。

## 基本原则

- 尊重其他玩家与管理人员，避免骚扰、歧视、恶意攻击或煽动争端。
- 不利用漏洞、外挂、脚本或异常机制获取不正当优势。
- 不破坏他人建筑、机器、容器或正常游戏体验。
- 不发布违法、欺诈、色情、暴力仇恨或其他不适宜内容。

## 性能与自动化

科技与自动化应在合理规模内建设。造成持续卡顿的装置可能被要求整改、限制或移除。

::: warning 重要
请勿制作高频红石、无节制实体堆积或未经测试的大规模自动化。性能规则以服务器实际运行情况为准。
:::

## 处理与申诉

管理团队会结合行为性质、影响范围与历史记录处理违规。若对处理结果存在疑问，请通过官方渠道提交完整信息；腐竹联系 QQ：2602346931。

::: danger
任何利用漏洞复制、绕过保护或干扰服务器稳定性的行为，均可能导致严肃处理。
:::
