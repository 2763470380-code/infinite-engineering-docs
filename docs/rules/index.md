# 服务器玩家行为规范与注意事项

欢迎来到无限工程。为了让所有玩家都能拥有稳定、公平、友善的游玩环境，请在开始正式游玩前阅读并遵守以下规则。

这里不是为了限制你的创造力，而是为了保证每一位玩家的努力都能被尊重，让每一座基地、每一条产线、每一次探索都建立在公平与秩序之上。

## 一、账号与身份规范

请使用自己的账号进行游戏。禁止盗号、借号进行违规行为，禁止冒充其他玩家、腐竹、管理成员或服务器官方身份。

禁止利用小号规避处罚、刷取奖励、占用资源、恶意干扰经济系统，或绕过任何服务器限制。

如果你的账号出现异常登录、被他人使用或发生纠纷，请及时联系腐竹。账号内发生的行为原则上由账号持有人承担责任。

## 二、聊天与社区交流规范

请保持基本礼貌。禁止辱骂、嘲讽、人身攻击、恶意带节奏、刷屏、阴阳怪气挑衅，或故意引发争吵。

禁止发布歧视、仇恨、色情、暴力、恐吓、诈骗、恶意引流、广告推广、外挂宣传、私服拉人等内容。

禁止在公共频道持续发送无意义信息、重复问题、过度表情、乱码、超长文本，或其他影响正常交流的内容。

玩家之间发生矛盾时，请优先私下沟通或联系腐竹处理。禁止在公共频道扩大冲突、围攻玩家或煽动他人参与争吵。

## 三、公平游玩与作弊行为

禁止使用任何外挂、作弊客户端、自动刷屏脚本等破坏公平性的工具。

禁止利用漏洞复制物品、刷钱、刷点券、刷任务奖励、绕过消耗、绕过冷却、绕过跨服限制，或破坏服务器经济平衡。

::: warning 漏洞处理
发现漏洞后应立即上报腐竹。主动上报不会受到处罚，腐竹会给予举报奖励；故意利用、传播或隐瞒漏洞，将视情况进行没收赃物、清除收益或封禁处理。
:::

## 四、基地、领地与建筑规范

禁止未经允许进入、破坏、修改、占用、搬空或干扰他人基地、机器、管道、仓库、农场、刷怪设施与自动化产线。

禁止在他人基地附近恶意圈地、堵门、围墙、覆盖地形、放置噪音机器、放置大量实体，或故意影响他人建设空间。

公共区域、主城、传送点、资源世界入口、任务区域附近禁止乱放方块、乱倒流体、乱丢实体、放置传送门，或建造影响通行的结构。

资源世界可以正常采集资源，但禁止恶意破坏传送点附近地形、制造无法通行的大坑、用流体覆盖入口，或放置危险装置影响其他玩家。

## 五、机器、性能与自动化规范

无限工程包含大量科技、魔法和自动化模组。请合理建设机器产线，避免无意义堆量、无限循环、掉落物堆积、实体堆积、管道堵塞，或长时间无人看管的高负载设备。

禁止故意制造卡服机器、红石高频、实体风暴、流体循环、物品循环、维度加载滥用、刷怪笼滥用，或任何明显影响 TPS 的结构。

大型自动化产线请尽量使用存储系统、管道过滤、垃圾处理、限速升级、开关控制和区块加载管理，避免产物溢出造成性能问题。

::: warning 性能整改
如果腐竹发现某个基地或机器明显影响服务器性能，有权要求玩家整改、临时关闭设备；必要时会直接移除异常机器或清理异常实体。
:::

## 六、经济、交易与合作规范

玩家之间可以自由交易、合作、组队发展；老玩家可以给予新玩家适当帮助，但请共同维护良好的发展环境。

禁止诈骗交易、恶意抬价扰乱市场、虚假宣传、收款不交货、借合作名义盗取物资，或利用新人不了解价格进行明显欺骗。

团队成员之间的物资、权限和基地管理请自行协商。加入他人团队前，请确认你信任对方；邀请他人进入团队前，也请确认权限设置。

因玩家私下合作产生的普通纠纷，腐竹会尽量协助判断，但不会无条件替任何一方承担损失。

::: warning 会员与点券商品
购买的 VIP 礼包中的物品、道具或点券商品，禁止随意给予其他玩家使用。首次发现会予以警告，第二次会没收相关物品。

禁止利用 VIP 礼包中的物品、道具或点券商品进行交易。
:::

## 七、PVP、恶意干扰与玩家安全

禁止恶意击杀、骗传送、堵门、推人进危险区域、引怪害人、引爆机器、引发辐射、制造陷阱，或利用环境伤害干扰他人正常游玩。

禁止在传送点、主城、公共设施、任务区域附近放置危险方块、攻击装置、伤害流体、爆炸物，或其他可能导致玩家损失的内容。

如果某些玩法允许战斗或竞争，也必须建立在双方明确同意的基础上。未经同意的恶意行为仍然会被视为违规。

## 八、跨服、维度与资源使用规范

跨服传送、随机传送、地皮、资源世界、主城等功能请按正常方式使用。禁止利用传送机制卡服、逃避限制、刷奖励，或绕过系统规则。

不同世界有不同用途：资源世界用于采集，家园或地皮世界用于长期建设，公共区域用于交流和传送。请不要在生存区域进行大规模破坏或长期占用。

禁止恶意加载大量区块、占用大量矿脉、长期挂机刷资源却不处理产物，或通过特殊方式让无人维护的机器持续造成负载。

## 九、腐竹处理原则

腐竹会根据违规行为的严重程度，采取提醒、警告、临时禁言、清除违规收益、回档处理、临时封禁或永久封禁等措施。

处罚并不只看单次行为，也会参考是否故意、是否重复、是否造成损失、是否影响其他玩家，以及是否主动配合处理。

请不要尝试钻规则漏洞。没有写在规则里的恶意行为，只要明显破坏公平、秩序、性能或其他玩家体验，仍然可能被处理。

如果你认为处罚存在误会，可以通过指定渠道进行申诉。申诉时请尽量提供时间、地点、截图、录像或相关说明，避免在公共频道争吵。

## 十、最后说明

请尊重其他玩家的时间、劳动和游戏体验。无限工程鼓励探索、合作、自动化和创造，但不接受破坏公平、破坏秩序和恶意影响他人的行为。

::: tip
进入无限工程游玩，即代表你已了解并愿意遵守本规则。祝你在这里建造出属于自己的一番小世界。
:::
